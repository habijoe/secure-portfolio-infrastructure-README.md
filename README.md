Project Description

This project involves the design, deployment, and security hardening of a multi-service Linux-based web infrastructure delivered in two major phases. In Part 1, virtual network sub-interfaces are configured on a Linux server, each hosting separate web applications. The first sub-interface runs an Apache2 web server that serves a static AUCA Education website under the domain name 24942.auca.ac.rw. The second sub-interface hosts a dynamic portfolio system using Nginx, where user information such as name, profession, skills, and profile image is retrieved dynamically from a backend database. The portfolio system supports Light and Dark mode switching and is accessible through the domain portfolio.auca.ac.rw.

Strong emphasis is placed on security configuration and compliance. Both websites are secured with SSL certificates and served over HTTPS. ModSecurity Web Application Firewall (WAF) is deployed to protect both Apache and Nginx web services. System-wide firewall rules are implemented to allow only HTTPS traffic, while SSH access is restricted to trusted IP addresses and secured with two-factor authentication (2FA). These controls ensure confidentiality, integrity, and restricted access to the hosted systems.

In Part 2, the dynamic portfolio system is containerized using Docker, where both the application frontend and database run as separate containers. Custom Docker images are built using the student’s ID for identification. Traefik is deployed as a reverse proxy and load balancer, distributing traffic across multiple Docker nodes running on Ubuntu and CentOS/RedHat servers. The system is designed for high availability, remaining accessible as long as at least one node is operational. Traefik is configured with TLS encryption using Let’s Encrypt, and additional security mechanisms such as user authentication and API-key–based access control are implemented to protect the application.

The final deliverable is a fully functional, secure, scalable, and well-documented web infrastructure demonstrating expertise in network configuration, web hosting, DevOps, containerization, security engineering, and load-balanced service deployment.
